# 0.3.7-dsh-0.2.2-rc.3 候选版

本版本用于 npm `next` 和 GitHub prerelease，正式提升需要维护者另行确认。真实 `.tgz` 安装、账号与 Session 验收尚未在本会话中记录，不建议直接替换重要会话使用的版本。

## 发布修复

原 `0.3.6-dsh-0.2.2-rc.3` tag 的发布在打包校验阶段失败，后续 npm 和 GitHub Release 发布步骤未执行。npm 12 把 `npm pack --json` 从数组改为以包名为 key 的对象，本版兼容两种格式，同时保留单包、版本、文件白名单和 hash 检查。

发布工作流与 PR CI 固定使用 npm `12.2.2`；CI 增加真实 `npm pack` 与 artifact 命令校验，已在 PR #16 中通过。旧 tag 保持不变，本版使用新的完整版本和 tag。

## 包含内容

- GitHub Copilot 多账号管理，支持 GitHub.com 与 GitHub Enterprise Cloud `*.ghe.com`，不同域名下的同名账号独立保留。
- 原生 Session 固定账号路由、受管理全局默认和所属 Host 的 `copilotAccounts` Remote；请求准备后捕获账号，不静默换号或重跑请求。
- 按账号隔离的 OAuth 凭据、replay 和传输状态，以及恢复、普通 fork、子代理继承和压缩路径的离线保护与测试。
- 账号页、底部徽标和面板统一显示已用额度；多账号归一化合计与 UTC 月进度参考不冒充共享余额或预测。
- 账号头像失败后的单次资料刷新；已有模型目录和用户 overrides 不被覆盖，不提供宿主内置模型目录刷新。
- 账号界面使用 DSH 语义主题变量；有名称的对话框让壁纸引擎识别账号浮层，配色可即时同步。
- 齿轮按原生账号菜单的 ARIA 语义跳转到“Copilot 账号”，不误点其他“更多”；排除隐藏副本，复用已打开的设置窗口。

Session 账号专属菜单没有包含在本版本中。底部“全局默认”只修改全局账号，不代表当前 Session 绑定账号。

## 兼容与验证边界

- 运行要求保持 Node `>=20`、DSH `^0.2.2-rc.1`、Cordis `~4.1.0`；版本后缀 rc3 是界面对照基准，不代表提高最低宿主要求。
- 独立浏览器页面使用合成账号验证过主题切换和设置跳转，不是实际 DSH 桌面窗口、真实登录或模型请求端到端验收。
- 原生集成测试依赖可选的本地 DSH fixture，跳过项不计为通过；每次发布以 Actions 日志报告的通过、失败和跳过数量为准。
- GHE 用量端点、实际计费口径、真实请求续接和压缩等未实测能力不能因离线测试通过而视为已验收。

## 安装

发布成功后，下载 Assets 中的 `dsh-github-copilot-accounts-0.3.7-dsh-0.2.2-rc.3.tgz`，在 DSH 插件管理器中导入，完整退出并重启 DSH。校验文件为同名 `.tgz.sha256`。也可在支持包说明符的安装入口显式选择 `dsh-github-copilot-accounts@next`。

GitHub 自动提供的 Source code `.zip` / `.tar.gz` 是源码归档，不是本次构建并发布到 npm 的安装包。测试 profile 不保证账号凭据隔离，请使用独立测试环境和测试 Session。

## 升级与回退

从 npm 旧版 `0.1.2-dsh-0.2.0-rc.1` 升级包含 Session 路由等变化，不仅是 UI 修复。更新前保留必要的环境备份，安装后完整重启，不删除凭据或历史会话。

旧版不能识别新增的受管理/固定账号路由，不能保证使用这些路由的会话直接降级后可用。切回 dist-tag 不会使已安装实例自动降级，也不等同于 Session 数据回滚；优先选择经验证的修复版本，不自动改绑会话或重跑请求。

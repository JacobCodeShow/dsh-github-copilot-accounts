# 0.3.8-dsh-0.2.2-rc.3 候选版

本候选优先通过 GitHub prerelease 的 `.tgz` 更新，不要求用户配置 npm 安全密钥。npm 发布默认关闭；GitHub 附件可用不代表 npm `next` 或插件市场已经更新。正式提升仍需要维护者确认。

## 发布渠道调整

- 构建、测试和打包校验通过后，独立创建 GitHub 预发布，上传同一 `.tgz` 与 `.tgz.sha256`，下载核对全部附件后才公开。
- 主任务不查询 npm 发布状态，不需要 npm Trusted Publisher 授权。默认不运行 npm 发布或 npm 产物交接。
- 只有仓库变量 `NPM_PUBLISH_ENABLED=true` 时，另一个任务才下载同一运行保存的 tarball，重新校验但不重新打包，再通过 OIDC 发布 npm `next`。
- npm 启用后的授权或网络失败仍明确报告，但已成功发布的 GitHub 安装包不回滚、不删除；不关闭 npm 认证，不新增长期 token，不自动提升 `latest`。
- `0.3.6` 的打包失败、`0.3.7` 的 npm 发布授权失败均保留原 tag。本版使用新版本，不覆盖旧 tag；保留 npm 12 包名对象与旧数组格式兼容和不可覆盖的哈希检查。

## 账号与 Session 能力

- GitHub Copilot 多账号管理，支持 GitHub.com 与 GitHub Enterprise Cloud `*.ghe.com`，不同域名下的同名账号独立保留。
- 原生 Session 固定账号路由、受管理全局默认及所属 Host 的 `copilotAccounts` Remote；请求准备后捕获账号，不静默换号或重跑请求。
- OAuth 凭据、replay 和传输状态按账号隔离；恢复、普通 fork、子代理继承和压缩路径具有离线保护与测试。
- 账号页、底部徽标和面板统一显示已用额度；多账号归一化合计和 UTC 月进度参考不冒充共享余额或预测。
- 头像失败后单次刷新资料；已有模型目录和用户 overrides 不覆盖，不提供宿主内置模型目录刷新。
- 账号界面使用 DSH 语义主题变量，壁纸引擎可识别有名称的账号浮层；齿轮按原生菜单语义进入“Copilot 账号”，不误点其他“更多”。

本版没有 Session 专属账号菜单。底部“全局默认”只修改全局账号，不代表当前 Session 绑定账号。

## 安装和验收范围

发布成功后，从 GitHub Release 的 Assets 下载 `dsh-github-copilot-accounts-0.3.8-dsh-0.2.2-rc.3.tgz`，在 DSH 插件管理器导入，完整退出并重启。用同名 `.tgz.sha256` 核对校验值。Source code `.zip` / `.tar.gz` 是源码归档，不是安装包。

运行要求保持 Node `>=20`、DSH `^0.2.2-rc.1`、Cordis `~4.1.0`；版本后缀 rc3 是界面对照基准，不提高最低宿主要求。

主题和设置跳转验证使用过合成账号的独立浏览器页面，不是实际 DSH 窗口或真实账号端到端验收。可选原生 fixture 缺失的测试按跳过报告，不计为通过；GHE 用量、真实请求续接和压缩等未实测能力不能因离线测试通过而视为已验收。

测试 profile 不保证账号凭据隔离；请使用独立测试环境和测试 Session。正式使用前应完成真实 `.tgz` 安装及账号/Session 验收。

## 升级与回退

从 npm 旧版 `0.1.2-dsh-0.2.0-rc.1` 升级包含 Session 路由等变化，不仅是 UI 修复。更新前保留必要备份，更新后完整重启，不删除凭据或历史会话。

旧版不能识别新增账号路由，不能保证相关会话直接降级后可用。切换 dist-tag 不等于已安装实例或 Session 数据回滚；优先使用经验证的修复版本，不自动改绑会话或重跑请求。
